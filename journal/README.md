# Golden tapes

A tape is a preserved, known-good Aeron Cluster journal: a sparse tarball of the
`archive/` and `consensus/` directories, recorded once by `scripts/record-tape.sh` and
committed beside its manifest and golden outputs.

**Tapes are immutable.** Record-time timestamps are wall clock, so a tape can never be
regenerated byte-identically. Never edit, overwrite, or re-record an existing tape — a
new scenario is a new name. The recording script enforces this.

| File | Contents |
|---|---|
| `<name>.tar.gz` | the journal: recording segments, `archive.catalog`, `recording.log` |
| `<name>.manifest.txt` | message count, SBE schema version, commit, date, machine |
| `<name>.golden-outputs.txt` | the ordered sequenced timestamps the service echoed |

Replay a tape with `scripts/replay-app.sh` (bare state machine) or
`scripts/replay-cluster.sh` (restart-recovery), or benchmark both with
`scripts/replay-bench.sh`. A tape recorded at schema version N must replay correctly
forever — these fixtures are the compatibility regression for the journal format.
